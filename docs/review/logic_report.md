# Отчёт по логике, маршрутам, БД и тестам

**Дата:** 25.11.2026  
**Категории:** логика / база данных / тесты

## Найденные проблемы и выполненные исправления

| ID | Файл / строки | Приоритет | Описание | Предложение / результат |
|---|---|---|---|---|
| LG-01 | `database/order_cost_query.sql`, исходные строки 24, 36, 102, 105 | Важно | SQL рассчитывал сумму как `quantity * unit_price - discount`, но Python-обработчики `app/views/sales_order_view.py:107,355` трактуют скидку как процент: `quantity * unit_price * (1 - discount / 100)`. Итоги SQL и приложения могли расходиться. | Исправлены все четыре выражения SQL на процентную формулу. |
| LG-02 | `app/models.py`, модель `ProductionOrderItem`, исходные строки 296–300; `database/schema.sql:133–136` | Важно | Ограничение проверяло `completed_quantity >= 0`, но не запрещало значение больше `quantity`. | Добавлено CHECK-ограничение `completed_quantity <= quantity` в ORM и SQL-схему. |
| LG-03 | `app/models.py`, `SpecificationOperation`; `database/schema.sql:103–110` | Рекомендация | `time_norm` и `op_quantity` были NOT NULL, но могли иметь нулевые или отрицательные значения, что искажает расчёт себестоимости. | Добавлены положительные CHECK-ограничения в ORM и SQL-схему. |
| LG-04 | `tests/test_auth.py` | Важно | Не было отдельного регрессионного теста, который проверяет попытку передать роль администратора при публичной регистрации. | Добавлен `test_register_cannot_assign_admin_role`. |

## Тестирование
В архиве присутствуют `tests/test_auth.py` и `tests/test_notes.py`. Синтаксическая компиляция исходников прошла успешно. Pytest не смог импортировать приложение, потому что в среде анализа отсутствует Flask. Перед сдачей необходимо установить зависимости и повторить `pytest -q`.

## Ограничения проверки
PostgreSQL и Postman в среде анализа не запускались. Выводы по SQL сделаны статическим чтением исходной схемы и запросов, без исполнения на сервере БД.
