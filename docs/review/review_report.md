## Выполненные правки
1. Запрет назначения роли администратора через публичную регистрацию.
2. Удаление повторного чтения JSON при регистрации.
3. Исправление DOM XSS в двух страницах заметок через `textContent`.
4. Устранение слабых значений по умолчанию для `SECRET_KEY` и пароля БД; обязательный ключ в production.
5. Передача `config_name` в функцию выбора конфигурации.
6. Согласование расчёта процентной скидки в SQL с логикой приложения.
7. Добавление ограничений на завершённое количество, норму времени и количество операций.
8. Добавление регрессионного теста против повышения привилегий.

## Результаты проверок
- Python compileall: успешно.
- Pytest: не выполнен из-за отсутствующего Flask в среде анализа (`ModuleNotFoundError`).
- Flake8/Pylint/Bandit/pip-audit: не запускались.
- PostgreSQL и Postman: не запускались.

## Заключение
По статическому анализу устранены выявленные дефекты высокого приоритета. До сдачи рекомендуется установить зависимости, выполнить `pytest -q`, прогнать Flake8 и Bandit, проверить SQL на тестовой PostgreSQL и вручную пройти основные сценарии через браузер/Postman. Это заключение не означает, что проект прошёл полный динамический аудит.
