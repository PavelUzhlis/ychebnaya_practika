# Карта репозитория Demo27

**Дата анализа:** 25.11.2026  
**Проект:** производственная информационная система на Flask / SQLAlchemy / PostgreSQL.

## Назначение проекта
Веб-приложение для работы с клиентами, продукцией, материалами, технологическими операциями, спецификациями, заказами на производство и заказами покупателей. Также присутствуют авторизация, роли пользователей и заметки.

## Структура

| Каталог / файл | Назначение |
|---|---|
| `app/` | Основной Python-пакет приложения |
| `app/blueprints/` | API-маршруты, в том числе авторизация и вспомогательные endpoint-ы |
| `app/dtos/` | Объекты передачи данных |
| `app/repositories/` | Доступ к данным и запросы к моделям |
| `app/services/` | Бизнес-логика |
| `app/views/` | Flask views / обработчики для доменов приложения |
| `app/models.py` | ORM-модели и ограничения данных |
| `app/config.py` | Конфигурации окружений и подключение к БД |
| `database/` | SQL-схема и запрос расчёта себестоимости заказа |
| `web/` | HTML-шаблоны и CSS/JavaScript интерфейса |
| `tests/` | Автоматические тесты авторизации и заметок |
| `image/` | Изображения проекта |
| `run.py` | Точка запуска Flask-приложения |
| `requirements.txt` | Зависимости Python |

## Запуск проекта

1. Установить Python 3.10+ (рекомендуется версия, совместимая с Flask-зависимостями).
2. Создать виртуальное окружение: `python -m venv .venv`.
3. Активировать окружение.
4. Установить пакеты: `pip install -r requirements.txt`.
5. Создать PostgreSQL-базу и задать `DATABASE_URL` либо `DATABASE_HOST`, `DATABASE_PORT`, `DATABASE_NAME`, `DATABASE_USER`, `DATABASE_PASSWORD`.
6. Задать уникальный `SECRET_KEY`; для production он обязателен.
7. Запустить: `python run.py`.

При старте `create_app()` регистрирует Blueprints, инициализирует расширения и вызывает `db.create_all()`. Для промышленного развёртывания следует применять миграции, а не полагаться только на `create_all()`.
