# Отчёт по структуре, стилю и читаемости

**Дата:** 25.11.2026  
**Категория:** стиль / структура / сопровождаемость

## Общая оценка
Структура проекта в целом модульная: присутствуют слои `models`, `dtos`, `repositories`, `services`, `views` и `blueprints`. Это упрощает навигацию, но параллельное наличие `app/blueprints/` и `app/views/` требует ясного правила, где размещать новые маршруты. Фактически `create_app()` регистрирует доменные Blueprints из `app/views/`, а из `app/blueprints/` регистрируются web и auth.
