# Материалы ревью Demo27

Отчёты учебной практики по модулю «Ревьюирование» находятся в этой папке:

- `repo_map.md` — карта проекта и запуск;
- `checklist.md` — чек-лист;
- `style_report.md` — структура и стиль;
- `style_report.txt` — результаты доступной статической проверки;
- `logic_report.md` — логика, БД и тесты;
- `security_report.md` — безопасность и зависимости;
- `review_report.md` — сводный итог.

Все замечания основаны на статическом чтении предоставленного архива. Запуск полного набора тестов и PostgreSQL в среде подготовки не был возможен из-за отсутствующих зависимостей и сервера БД.


Для установки инструментов ревью используйте `pip install -r requirements-dev.txt`.
Скрипт `github_upload.ps1` создаёт ветку и формирует 10 отдельных коммитов в соответствии с учебным заданием. Перед запуском замените `familiya` на свою фамилию латиницей.
